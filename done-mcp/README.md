# Done MCP Server

MCP (Model Context Protocol) server for the Done life-logging app. Lets LLMs like Claude and ChatGPT query your activities, emotions, behavioral patterns, and skills — then write back insights.

## Architecture

```
iOS App (source of truth)
  └─ SupabaseSyncService (Combine, 2s debounce)
       └─ Supabase PostgreSQL
            └─ MCP Server (stdio, 7 tools)
                 └─ Claude / ChatGPT
```

- **iOS is the single source of truth.** Supabase is a read-only mirror for LLMs.
- **AI writes are physically isolated** in separate tables (`ai_insights`, `ai_summaries`, `ai_questions`). LLMs cannot modify human data.
- **Row Level Security (RLS)** enforces per-user data isolation.

## What was built

### 1. Supabase Schema (`supabase/migrations/001_initial_schema.sql`)

Human-owned tables (iOS syncs here, MCP reads only):
- `events` — calendar events and todos (title, type, time ranges, status, recurrence, etc.)
- `event_logs` — activity reflections (completion status, effort 1-5, emotions, behaviors, notes)
- `event_feedback` — structured feedback records
- `event_types` — user-defined activity categories (Exercise, Study, Work, etc.)
- `todo_lists` — todo list containers
- `skill_insights` — skills extracted from activities with practice hours

AI-owned tables (MCP can write, humans read only):
- `ai_insights` — patterns, trends, milestones discovered by LLMs
- `ai_summaries` — period summaries generated by LLMs
- `ai_questions` — questions LLMs want to ask the user

### 2. MCP Server (`src/`)

TypeScript server using `@modelcontextprotocol/sdk`, communicates via stdio.

**Read tools:**
| Tool | Description |
|------|-------------|
| `get_user_context` | User profile, event types, skill summary, emotion/behavior frequency |
| `query_events` | Filter by date range, type, status, keyword |
| `query_logs` | Filter by emotions, behaviors, effort range, date |
| `get_skills` | Skill insights with aggregated hours |

**Write tools (AI-isolated):**
| Tool | Description |
|------|-------------|
| `save_insight` | Save a discovered pattern/trend/milestone |
| `save_summary` | Save a period summary |
| `leave_question` | Leave a question for the user to answer in-app |

### 3. iOS Sync Service (`Done/Services/SupabaseSyncService.swift`)

Zero-dependency sync layer using raw `URLSession` — no Supabase SDK needed.

- Subscribes to `EventStore`'s `@Published` properties via Combine
- Debounces changes (2 seconds) then upserts to Supabase
- Runs a full sync on app launch
- Handles deletions by diffing current vs. previous ID sets
- Non-invasive: no changes to EventStore or any existing code

## Setup

### Prerequisites
- Node.js 20+
- A Supabase project

### 1. Database
Run `supabase/migrations/001_initial_schema.sql` in your Supabase SQL Editor.

### 2. MCP Server
```bash
cd done-mcp
cp .env.example .env
# Edit .env with your Supabase URL, service role key, and user ID
npm install
npm run build
```

### 3. Test
```bash
# Seed test data
node seed-realistic.mjs

# Verify MCP server
printf '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2024-11-05","capabilities":{},"clientInfo":{"name":"test","version":"0.1"}}}\n{"jsonrpc":"2.0","method":"notifications/initialized","params":{}}\n{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"get_user_context","arguments":{}}}\n' \
  | node dist/index.js
```

### 4. Claude Desktop (optional)
Add to `~/Library/Application Support/Claude/claude_desktop_config.json`:
```json
{
  "mcpServers": {
    "done-life-log": {
      "command": "node",
      "args": ["/path/to/done-mcp/dist/index.js"],
      "env": {
        "SUPABASE_URL": "https://your-project.supabase.co",
        "SUPABASE_SERVICE_ROLE_KEY": "your-key",
        "DONE_USER_ID": "your-user-uuid"
      }
    }
  }
}
```

### 5. iOS Sync
`SupabaseSyncService` is already wired into `ContentView.swift`. Update the URL, API key, and user ID in `SupabaseSyncConfig` to match your Supabase project.

## Simulator Testing

Inject mock data directly into the simulator's UserDefaults:
```bash
PLIST=$(xcrun simctl get_app_container booted wordless.shiqiliuyifanmei.app data)/Library/Preferences/wordless.shiqiliuyifanmei.app.plist
swift inject-mock-data.swift "$PLIST"
```

Then relaunch the app — data syncs to Supabase automatically.
